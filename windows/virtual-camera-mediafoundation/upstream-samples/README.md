# Archived Microsoft VirtualCamera sample material

These projects and wrapper sources came from Microsoft's Windows Camera VirtualCamera sample. They are retained as reference material with the parent `LICENSE` and original per-file copyright notices intact.

They are intentionally excluded from `VirtualCameraSample.sln`, `dev-build-vcam.ps1`, the shipped DLL, and the installer/host. Paths inside the archived sample projects may still reflect the original sample layout; this archive is not a supported build target.

OpenCamBridge production code is in `../VirtualCameraMediaSource`, `../VirtualCamera_Installer`, and `../rust-frame-producer`.
